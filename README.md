Project Description

Lie Generator is a fun and entertaining web project that generates funny and ridiculous excuses for different situations. Users can select a situation and get a random excuse instantly.

The Problem (that doesn't exist)

Sometimes we have absolutely no idea what excuse to give when we are late, forget something, miss an event, or simply don't want to explain ourselves. 🤥

The Solution (that nobody asked for)

Our Lie Generator solves this completely unnecessary problem by providing funny and creative excuses at the click of a button. Because sometimes, the perfect excuse is more important than the truth! 😂
